## NYC Utility Burden Figures

This folder groups New York City-specific utility burden outputs.

- `Bars/`: benchmark-year borough bar chart
- `Trends/`: borough trend figures and change tables
- `PUMA-Heatmap/`: 2023 PUMA heatmap outputs
- `Legacy-Heatmap/`: earlier 2021 heatmap outputs
- `Subgroup-Maps/`: Black/White borough comparison maps and tables

Each subfolder includes the source script when available, along with exported figure and table files.
